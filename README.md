# 自律 - 习惯养成与形象管理

一款专为青少年设计的个人形象管理应用，基于自律习惯养成手册打造。

## 功能特性

### 📋 每日打卡系统
- 10项每日必做任务清单
- 连续打卡统计和补打卡支持
- 今日完成率环形图展示
- 日历热力图查看历史完成率

### 🏋️ 室内训练计划
- 严格按照手册的每周运动计划（周一/三/五力量、周二/四有氧）
- 8周渐进式训练方案（适应期→减脂期→塑形期→冲刺期）
- 每个动作的详细要领和常见错误提示
- 内置倒计时器（组间休息和时长型动作）

### 🥗 饮食指导
- "一拳头主食 + 一掌心蛋白质 + 两拳头蔬菜"口诀
- 早餐、午餐、晚餐、加餐具体建议
- 食物红绿灯列表（绿灯/红灯食物）
- 走读/住校差异化饮食建议

### 📊 运动记录与数据分析
- 俯卧撑总次数、深蹲次数趋势曲线
- 平板支撑、靠墙静蹲最长时长曲线
- 每周有氧总时长柱状图
- 每日完成率柱状图
- 照片对比功能（每周日拍摄）

### 🏆 心理激励
- 每日金句推送（50+条激励语录）
- 12枚成就徽章系统
- 恐惧挑战每周任务
- 匿名树洞记录功能

## 技术栈

- **Flutter**: 跨平台UI框架
- **液态玻璃UI**: Apple Liquid Glass设计语言
- **SQLite**: 本地数据库（完全离线可用）
- **Provider**: 状态管理
- **fl_chart**: 数据可视化图表
- **flutter_local_notifications**: 本地通知提醒

## 系统要求

- Android 7.0+ (API 24)
- 目标Android 14 (API 34)

## 构建

```bash
# 获取依赖
flutter pub get

# 运行分析
flutter analyze

# 运行测试
flutter test

# 构建APK
flutter build apk --release
```

## GitHub Actions

项目已配置自动构建，推送代码到 main/master 分支时会自动：
1. 安装依赖
2. 运行静态分析
3. 执行测试
4. 构建Release APK
5. 上传APK到Artifacts
